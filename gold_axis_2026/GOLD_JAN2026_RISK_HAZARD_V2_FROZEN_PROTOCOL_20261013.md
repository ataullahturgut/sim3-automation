## Target: First-passage event hazard (not prediction of daily mean)
At completed session t, label y3=1 if among next 1,2,3 NY17 sessions the **chronological lowest M15 low** is <=0.97*LAST_CURRENT_SESSION_CLOSE, else 0; future label unavailable at last 3 sessions. This is a downside *excursion* event, not direction at close or tradeable bid/ask guarantee. Additional y1 1-session and recovery direction evaluated ex-post only. Cohorts evaluated in nonoverlapping quarterly blocks and month-level event clustering, overlapping daily origin labels are not independent.
## Features, information cutoffs
All as of session t close using no next-session data: `r5,r20,r60` completed session close changes; `dd_ordered` current intraday max-high-to-subsequent-low percent; `close_from_hi` = current close / max current high -1; `close_location` = (close-lowest current low)/(high-low); `shock` = current absolute orderedDD / median(prev60 sessions abs orderedDD), using only prev 60 and capped at 6; `vol` sd of last 20 completed 1-day close-to-close log returns; `risk_in_gold` prior S4 state is NOT a feature so no cyclic predictions. Winsorize each feature using PRE-2024 train 1%/99% quantiles, then standardize using train means/std only. No news/dollars/unknown-release-time metal data as model inputs.
## Model A — constrained, regularized pooled hazard logistic
Binary logit trained only on 2022–23, L2 penalty λ=2 applied all slopes not intercept, 7 predictors [r5,r20,r60,dd_ordered,close_from_hi,close_location,shock,vol] (actually 8 features; use exactly these eight). No hyperparameter grid; 250 IRLS iterations or convergence delta<1e-8. Prior probabilities not altered for class balance. All train records need 60 complete prior sessions for shock and future 3 eligible sessions still in <=2023. If missing, exclude with explicit counts. Prior states from 2022 early training have insufficient 60-day warmup; begin when available.
Model B — monotone prior-informed logistic as a sensitivity (not extra selection): impose dd_ordered and close_from_hi negative coefficients for risk, optionally no monotone optimization if implementation not robust; better do no model B and report predictor coefficients uncertainty. Baseline event rate rolling trailing 180 sessions as-of; no benchmark fitting 2024/25.
