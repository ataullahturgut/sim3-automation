## Frozen model/training parameters before score
- Earlier HAR: 3 predictors `logRV(last1), mean(logRV(last5)), mean(logRV(last22))`, ridge alpha=10 standardized to prior fitting rows, unpenalized intercept. Fit on **most recent 500 prior eligible training-feature sessions** with completed outcomes, min 60. This is model `ROLL500`.
- Augmented `ROLL500_EVENT` adds **one binary event flag** with same ridge alpha10: DAY=official scheduled NFP or CPI release at US 08:30 ET on future DAY date; OVN=regular FOMC statement at US 14:00 ET on OVN start-date. Event schedule must be known before issue; source linked to archived macro series is retrospective schedule surrogate; exceptions/revisions **not first-print proven**. Flag is standardized using only prior fitting rows, fallback sd 1 if sparse.
- Controls `PERSIST5` previous 5 completed same-session `logRV` mean, `CLIM60` previous 60 logRV mean, existing PR #91 `H3A_HAR` exact same date / source. Avoid "HAR beats weak baseline" if Persist5 beats it. Source 2025 inspected.
- Train for 2023,24,25 using historical completed labels only and rolling latest500; do not retrospectively freeze 2025 if model specification itself requires rolling retrain, but historical performance clearly previously analyzed; compare to truly frozen original H3A. Standardization of event flag in fitted rolling panel only.
- Primary: QLIKE `rv/f - ln(rv/f)-1`; secondary logMSE; per session type, per calendar year, event vs non-event N. Gate requires augmented ROLL500_EVENT beat BOTH PERSIST5 and ROLL500 in QLIKE in **2023 and 2024 separately and 2025 opened**, and 3-month-block bootstrap 95% improvement CI positive, with Holm over DAY and OVN. Else NO PROMOTION.
