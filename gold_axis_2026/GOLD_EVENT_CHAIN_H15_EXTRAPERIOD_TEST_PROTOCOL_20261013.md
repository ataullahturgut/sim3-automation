Frozen evaluation before reading new outcomes:
1. Daily midpoint close = final *completed* 15m bid+ask-mid quote of NY17 session; >=70 bars and weekdays only. Observations from future t not allowed into current features.
2. `r20=100*(p_t/p_{t-20}-1)` as of session close t; `r1` similarly, trailing 60 *previously completed* eligible sessions' daily return sample std `sd60` (min 40). No day-t value inside `sd60`. `zr20=r20/(sd60*sqrt(20))`.
3. Primary outcomes over **next 10 eligible close sessions**: first passage of +3% or -3% vs close t, with UP-first/DOWN-first/NONE. If never hits either, **NONE**. If closes cross both directions on different days, earliest wins; retain `both` too.
4. H03 PRIMARY metric: non-parametric rank AUC using signed `r20` to classify DOWN-first vs UP-first **conditional on any first passage**. Require same year and pooled; report N downs/ups, AUC; AUC=0.5 chance. Because 10d horizons overlap and priors trend, report **episode/stride sensitivity**: every 10th day offsets 0–9; effective N can be much smaller; no p-value from naive i.i.d. daily scoring.
