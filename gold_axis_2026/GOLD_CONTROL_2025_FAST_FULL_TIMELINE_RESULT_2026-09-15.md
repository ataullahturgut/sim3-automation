## 1. Correction / superseded interpretation

The earlier event-conditioned FAST interpretation (`11/19` event-days had the same prior FAST direction) is **withdrawn as a FAST alarm-performance result**.

Reason: that calculation started from the 19 realized volatility events and looked backward at FAST. It therefore hid FAST signals that were issued when no nearby volatility event occurred and could not measure false-warning behavior.

It may remain only as a historical directional-alignment diagnostic. It is **not retained on this result page and must not be cited as FAST warning accuracy**.

The current evaluation direction is:

> run FAST across the complete governed 2025 timeline first -> retain every daily FAST state and every new ROBUST episode onset -> only then overlay the frozen 19 volatility event-days.

No FAST threshold or core rule was changed.

## 5. Early-warning timing sensitivity — NOT a frozen alarm window

No single warning window is selected after inspecting these results. To avoid post-hoc thresholding, the raw sensitivity is retained for several pre-declared descriptive windows:

| Same-direction volatility event after a new FAST onset | FAST onsets satisfying condition | Total onsets |
|---|---:|---:|
| within 1 governed day, strictly before event | **1** | 22 |
| within 3 governed days, strictly before event | **2** | 22 |
| within 5 governed days, strictly before event | **3** | 22 |
| within 10 governed days, strictly before event | **5** | 22 |
| same event day | **1** | 22 |

These counts are descriptive sensitivity only. They do **not** yet define precision, false-alarm rate, or an approved FAST warning horizon.

A formal false-warning rate requires a separately preregistered warning-validity window before it can be promoted as a performance metric.

## 6. Current interpretation

FAST is retained as a **daily tactical trend-state engine**, not proven as a standalone volatility-warning engine.

The current evidence supports these statements only:

1. FAST generated **22 distinct new robust-state episodes** in 2025.
2. The frozen volatility universe contains **19 abnormal event-days**.
3. Only a small subset of FAST episode starts occurred shortly before a same-direction volatility event under 1/3/5/10 governed-day sensitivity windows.
4. Event-day directional alignment must not be substituted for warning precision.
5. The old `11/19` event-conditioned directional-alignment number is **not current FAST alarm performance**.
6. No FAST rule, volatility-event rule, source, threshold, or production state was changed from these results.

This page is the current FAST result record for the 2025 volatility challenge until a separately governed successor evaluation replaces it.
