# Security Policy

## Sensitive files

Never commit or upload:

- Browser user-data or profile folders
- Generated reports and captured tasks
- Runtime logs, state files, lock files, or recovery artifacts
- API keys, access tokens, cookies, session data, or credentials
- Machine-specific absolute paths that reveal usernames or private project locations

## Reporting a vulnerability

Report security issues privately to the repository owner. Do not publish credentials, private project data, screenshots containing personal information, or reproducible secrets in a public issue.

## Local execution

This project automates desktop applications and executes local scripts. Review the source and configuration before running it. Use a non-production test project for initial validation.
